# checkkhum

checkkhum-website: the เช็กคุ้ม (CheckKhum) car and travel insurance site, a static page built around quotation requests.

- Open `index.html` in a browser; there is no build step.
- Set the phone number, LINE ID and LINE QR image in the `CONTACT` object at the top of `assets/app.js`.
- Design tokens, layout and open items: [`DESIGN.md`](DESIGN.md).
